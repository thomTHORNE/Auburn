COLOUR GRID · EXPLORATION
Built like the basics. The palette is the primitives: each colour you name becomes a ramp around it, at the seven steps of lightness. The grid is the semantic tier: a kind is a row and picks one ramp; a level is a column; each cell names one step. Home takes each part's colour from the cell it is plotted on.
