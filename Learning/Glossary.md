# Glossary

One line per term, plus where it is explained properly. Glance here when a word in a `Learning/` document or in conversation isn't landing.

The glossary defines nothing on its own — each entry is a reminder, and the linked section owns the actual explanation. If the two disagree, the explainer is right.

---

| Term | | In depth |
|---|---|---|
| Contrast | How many times brighter the lighter of two colours is: 1 is identical, 21 is white on black; body text reads from about 4.5 | [Colour](Colour.md#a-line-you-cannot-find) |
| OKLCH | A way of writing a colour as lightness, chroma and hue, spaced to match how the eye sees them | [Colour](Colour.md#three-dials-not-one) |
| Lightness, chroma, hue | How bright a colour reads, how colourful it is, and which colour it is | [Colour](Colour.md#three-dials-not-one) |
| Ramp | Shades of one colour in even steps of lightness, hue held, chroma easing at the ends | [Colour](Colour.md#a-ramp) |
| Role | What kind of thing an element is (accent, information, set apart), as opposed to how loud it is | [Colour](Colour.md#what-each-path-costs) |
| Spacing scale | A short list of sizes, each clearly bigger than the last, that every gap is taken from | [Spacing](Spacing.md#space-is-a-statement) |
| Leading | The space a line of text carries above and below its letters | [Spacing](Spacing.md#space-is-a-statement) |
| Optical correction | Spacing measured to what the eye sees rather than to layout boxes | [Spacing](Spacing.md#space-is-a-statement) |
| Hierarchy | The order in which a screen's elements are seen, set by every visual property at once | [Hierarchy](Hierarchy.md#a-ranking-with-several-voters) |
| Level | One rung of the hierarchy: primary, secondary or supporting | [Hierarchy](Hierarchy.md#a-ranking-with-several-voters) |
